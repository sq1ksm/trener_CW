Instrukcja obsługi — Trener Telegrafii CW

1. Podłączenie adaptera Vail MIDI

  1. Podłącz adapter Vail z kluczem telegraficznym (manipulatorem łopatkowym lub kluczem sztorcowym) do portu USB komputera.
  2. Otwórz trener w przeglądarce wspierającej Web MIDI API (Chrome, Edge, Opera lub Brave).
  3. Zaakceptuj prośbę przeglądarki o dostęp do urządzeń MIDI.
  4. Trener automatycznie przełączy adapter Vail z domyślnego trybu klawiatury w tryb MIDI (komunikat CC#0 = 1) oraz ustawi prędkość WPM i tryb klucza.
Brak dźwięku po starcie? Przeglądarki blokują dźwięk do pierwszej interakcji użytkownika. Kliknij dowolne miejsce na stronie lub przycisk Włącz dźwięk w górnym pasku.

2. Tryby pracy klucza (Dongle)

  • Iambic A (Program 7): Standardowy tryb dla manipulatora dwułopatkowego. Po puszczeniu obu łopatek klucz kończy aktualnie nadawany element (kropkę lub kreskę).
  • Iambic B (Program 8): Po puszczeniu obu łopatek w trakcie nadawania elementu klucz dodaje jeszcze jeden naprzemienny element z pamięci.
  • Straight Key (Program 1): Tryb klucza sztorcowego (lub klucza typu Bug) — długość kropek i kresek zależy wyłącznie od czasu trzymania styku przez operatora.

3. Tempo WPM, przerwy i kontrola rytmu

  • WPM (Words Per Minute): Prędkość nadawania (5–45 WPM). Jednostka podstawowa dit (czas trwania kropki) obliczana jest ze wzoru 1200 / WPM ms (np. dla 20 WPM wynosi 60 ms).
  • Przerwa między literami (poszerzenie): Określa, po jakim czasie bezczynności dekoder uznaje literę za zakończoną (domyślnie 3.0x dit). Zwiększenie tej wartości ułatwia naukę początkującym (metoda Farnswortha).
  • Maks. przerwa w wyrazie (limit): Jeśli zaznaczono opcję resetowania przy zbyt długiej przerwie, przekroczenie tego czasu w trakcie nadawania 6-znakowej grupy zeruje bieżący wyraz, wymuszając płynne nadawanie całego znaku.
  • Synchronizuj dekoder z WPM: Zalecane. Dekoder zawsze dopasowuje próg rozróżniania kropki od kreski do prędkości ustawionej w adapterze.
Wskazówka: Przycisk Odsłuchaj wzór pozwala najpierw usłyszeć prawidłowy rytm wylosowanego znaku wywoławczego lub grupy znaków przed jej nadaniem.
