Twoja obecna przeglądarka nie pozwala na obsługę klucza telegraficznego przez USB/MIDI (część funkcji aplikacji może nie działać).

Aby korzystać z pełnych możliwości Trenera Telegrafii CW, uruchom stronę w jednej z obsługiwanych przeglądarek:

  • Google Chrome (Windows, macOS, Linux, Android)
  • Microsoft Edge (Windows, macOS)
  • Opera / Brave / Vivaldi

Uwaga: Przeglądarki na urządzeniach Apple iPhone/iPad (iOS/iPadOS) oraz Safari nie obsługują standardu Web MIDI.
